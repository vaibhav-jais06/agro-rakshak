# Agro Rakshak 🌱🛡️

**Empowering Farmers with AI-Driven Intelligence**

*A comprehensive smart agriculture platform built for the Smart India Hackathon (SIH).*

## 📖 Overview
Agro Rakshak (meaning "Agricultural Protector") is an end-to-end, multilingual platform designed to enhance farmer productivity. By leveraging modern AI and data analytics, Agro Rakshak provides hyper-personalized, actionable insights to farmers exactly when they need them.

## ✨ Key Features
- **Weather Intelligence System**: Real-time localized weather updates and smart crop-specific alerts based on upcoming conditions.
- **Crop Recommendations**: AI-driven crop selection based on soil health parameters, weather, and market demand.
- **Pesticide Predictor**: Intelligent diagnosis of crop diseases and accurate pesticide recommendations.
- **Soil Health Dashboard**: Upload and track soil testing results to optimize fertilizer usage.
- **Agri Shop Integration**: A marketplace to connect farmers directly with reliable agricultural input suppliers.
- **Multilingual Support**: fully localized (English, Hindi, Bengali, Tamil, Telugu) to reach farmers in their native tongue.
- **Knowledge Hub**: Accessible library of farming best practices, post-harvest storage guides, and success stories.

## 🛠️ Technology Stack
- **Frontend**: React.js, Tailwind CSS, Capacitor (for cross-platform mobile support)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **AI/ML Integration**: Generative AI / Groq SDK for smart predictions
- **PWA Ready**: Works offline and installs natively on devices via Service Workers.

## 🚀 Getting Started Locally (For Judges / Internal Evaluation)

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start the Frontend Development Server**
   ```bash
   npm start
   ```
   The app will run locally at `http://localhost:3000`.

3. **Start the Backend**
   ```bash
   cd backend
   npm install
   npm start
   ```
   The API will be available on port 5000 (default).

## 💡 The Problem We Solve
Farmers often lack real-time, actionable insights tailored to their specific soil conditions and local weather. Agro Rakshak bridges this gap by democratizing access to expert-level agricultural guidance, minimizing crop failure risks, and maximizing yield potential.
